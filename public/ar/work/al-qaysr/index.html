Al Qaysr · قائمة طعام رقمية

قائمة طعام سريعة مصمّمة للجوّال أولًا لمطعم في بيروت. بحث، وأسعار السفري والصالة من ملف JSON واحد، ورموز QR قابلة للطباعة للطاولات. بلا قاعدة بيانات ولا تسجيل دخول: HTML بسيط يمكن استضافته في أي مكان.

المشكلة

احتاج مطعم في بيروت إلى قائمة طعام سريعة يفتحها الزبائن من رمز QR على الطاولة، بأسعار منفصلة للصالة والسفري، ويمكن لأي استضافة تقديمها من دون قاعدة بيانات.

ما بنيته

  • قائمتان من لائحة واحدة: السفري والصالة، لكل منهما أسعارها، من إدخال واحد لكل طبق.
  • تصفّح سريع: بحث، وشريط أقسام ثابت، وتفاصيل لكل طبق.
  • الطلب عبر واتساب: سلة تبني رسالة واحدة جاهزة بالكميات والأسعار والمجموع. بلا خادم ولا خطوة دفع.
  • واجهة عربية تُطبَّق قبل ظهور الصفحة، فلا تومض من اليسار إلى اليمين أبدًا.
  • بيانات لمحركات البحث: المطعم وقائمته كاملة بصيغة schema.org JSON-LD، مع سعر كل طبق في قائمته.
  • رموز QR قابلة للطباعة للطاولات، ولوحة مخفية للمالك لتعديل الأطباق والأسعار والصور.

كيف يعمل

القائمة كلها ملف JSON واحد مدمج في نسخة Next.js ثابتة، فيكون الموقع العام HTML بسيطًا. يحمل كل طبق كائن أسعار، ومنه يُعرف في أي قائمة يظهر. تُحفظ تعديلات المالك في Supabase وتصل إلى الموقع بإعادة بنائه.

menu.json · one dish, two menus"prices": { "TABLES": 22.22, "TAKE_AWAY": 16.66 }  // both, different price
"prices": { "TABLES": 5 }                          // dine-in only
"prices": { "TAKE_AWAY": 20 }                       // take-away only

قرارات أساسية

  • ثابت عن قصد: لا قاعدة بيانات أثناء التشغيل، فيمكن لأي استضافة تقديمه ولا شيء يحتاج إلى إبقائه متصلًا.
  • تعطّل قاعدة البيانات لا يُسقط القائمة: يسحب البناء أحدث نسخة من القائمة، ويعود إلى الملف المحفوظ إذا تعذّر الوصول إلى قاعدة البيانات.
  • الرابط المخفي ليس حماية: لوحة المالك محميّة بتسجيل الدخول وبصلاحيات الصفوف في قاعدة البيانات.
  • كلمات المطعم تبقى كلماته: تُعرض أسماء الأطباق كما كتبها، دون ترجمة آلية، وأي وصف كُتب لطبق فارغ يُعلَّم ليراجعه المالك.
