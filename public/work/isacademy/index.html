The problem

An answer pulled from a stack of PDFs is only useful if you can check it. An assistant that sounds sure of itself but cites the wrong page, or answers a question about a chart from the text alone, is worse than no answer.

Isacademy had to work in English and Arabic, and show where every claim comes from.

What I built

  • Grounded answers written only from the retrieved passages, with every source named by document and page.
  • Visual questions get visuals: ask about “Figure 3” or “the chart on page 15” and you see that figure or page, then Gemini’s reading of it.
  • A semantic PCA map on every question: where it sits among its 25 nearest passages, which cluster it belongs to, and why the closest ones are close.
  • Data analysis for CSV and Excel files: profiling, PCA and interactive charts.
  • A full Arabic interface, right to left, while file names, numbers and charts stay left to right.
  • Reports in Markdown, HTML and PDF.

How it works

Three small agents and one plain pipeline function, with no agent framework. A query agent works out what kind of question it is, a retrieval agent searches ChromaDB with a similarity threshold, and an analysis agent has Gemini write the answer from that evidence. Embeddings run locally; Gemini is the only AI provider.

rag pipelinePDF → PyMuPDF → pages, tables, figures
    → sentence-aligned chunks
    → BAAI/bge-small-en-v1.5 embeddings
    → ChromaDB (cosine, persistent)
    → top-K → similarity threshold
    → Gemini answer + page citations

Key decisions

  • Gemini never writes a page number. Citations are built in Python from each chunk’s metadata, so they can’t be invented.
  • It says when it doesn’t know. If nothing scores above the similarity threshold, it says so instead of answering.
  • Similarity is measured on the full vectors, never on the 2-D map, and the interface says the map is an approximation.
  • Documents are data, not instructions: prompts tell Gemini to use only the supplied context and never to follow text inside it.
  • Re-uploading a file does nothing: a document’s ID is the SHA-256 of its bytes.
