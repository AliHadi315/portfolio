The problem

University life is scattered across course portals, PDFs, group chats, calendars and notes apps, and none of them talk to each other, so the student ends up as the glue.

UniMate puts it all behind one login.

What I built

  • A dashboard that answers “what needs attention today?”: live counters, progress and the nearest deadlines.
  • Syllabus to tasks, with a human in the loop: a PDF becomes proposed deadlines that you review before anything is saved.
  • A weekly timetable with lecture blocks sized to their real length.
  • Classmates without invites: every course code is automatically a group room, plus direct messages.
  • Shared study resources, private by default and shared with classmates on the same course when you choose.
  • Progress and a weighted GPA, plus a study assistant grounded in your own courses and tasks.

How it works

A Laravel 12 JSON API secured with Sanctum bearer tokens, and a front end in plain HTML, CSS and JavaScript, with no framework and no build step. Every request is authenticated, validated and authorised before it reaches any data.

every requestrequest → authenticate → validate → authorize → logic → JSON

syllabus importPDF → text → model → validated proposals
    → the student ticks what is real → tasks

Key decisions

  • Authorization before data, covered by tests: one student can never read another student’s tasks, resources or messages.
  • Classmates are derived, not managed: two students are classmates when they share a university and a course code, so there is nothing to keep in sync.
  • AI output is checked: extracted deadlines pass type, date and size checks, and the student confirms them.
  • No build step: it runs as it is on any PHP 8.2+ host.
